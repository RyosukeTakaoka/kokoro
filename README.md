# Kokoro

school_Message の issue #87(スロット案の素材)と #91(コード例)を元にした、
**スロットの演出だけを本気で作り込んだ試作アプリ**です。本番(school_Message)に入れる前に、
演出の気持ちよさ・テンポ・振動をこのアプリで試します。自分用なので、データ保存などは簡易的です。

> issue では「パチンコ」と書いていますが、中身はスロット(パチスロ)です。

## 動かし方

1. `Kokoro.xcodeproj` を Xcode 16 以降で開く
2. **Signing & Capabilities** で自分の Team を選ぶ(Bundle ID は `app.takaoka.com.kokoro`)
3. **iPhone 実機**で実行する(振動は Taptic Engine のある iPhone だけ。iPad とシミュレータでは振動しません)

iOS 17 以上。外部ライブラリ・音声ファイル・画像素材は使っていません(効果音と BGM はその場で波形を合成しています)。

## 遊び方

- **START**(またはリールをタップ)でレバーオン。1 回 3 枚
- **STOP** を左から順に押す(リールをタップしても次のリールが止まる)
- 中段に 3 つ揃うと払い出し。**7 7 7 = BIG BONUS**、**BAR BAR BAR = REGULAR BONUS**
- BIG のあとは **KOKORO RUSH**(15 回転、約 66% で次のボーナス = 連チャン)
- メダルが無くなったら「メダルを借りる」。**AUTO** で自動プレイ
- 右上の歯車で 音・振動のオンオフ、データ(ハマり G 数・BIG/REG 回数・履歴)、スペック表

## 演出の流れ(issue の案 → 実装)

| issue の案 | 実装 |
|---|---|
| 不定比強化(いつ当たるかわからない) | レバーの瞬間に内部抽選。演出はすべて結果から逆算した「台本」(`SpinPlan`) |
| リーチ(近接効果)と寸止め | ハズレでも 9% でリーチ。最後のリールは 7 が中段の**半コマ上でじわじわ粘り**、ハズレだと中段を**通り過ぎて 1 コマ下**に止まる(「あと1コマ…」) |
| 「静寂 → タメ → 開放」の 3 段構成 | ① 最後の STOP で **音・振動・BGM を全部切って画面を暗くする(0.28 秒)** ② 1.6〜3.0 秒のタメ(色が段階的に上がる・うなり音がせり上がる・振動の間隔が詰まって強くなる・画面が寄って揺れる) ③ 無音の一瞬のあと爆発(白フラッシュ・紙吹雪・メダル・火花・大きな揺れ・最大強度の振動・ファンファーレ) |
| 期待度の色(青 → 赤 → 金 → 虹) | 青 3% / 緑 9% / 赤 44% / 金 78% / 虹 100%(シミュレーションで確認)。タメ中に期待度ゲージと色の文字が出る |
| チャンスボタン(押せ!! / 連打しろ!!) | 赤以上のリーチで **PUSH!** か **連打!!**(12 回でゲージ満タン)。押すたびに振動と音が強くなる |
| 保留・予告 | レバーオン時の予告(チャンス? → 激アツ!! → 確定!!!)、第 3 停止ボタンの色予告(虹ボタン = 確定) |
| 告知(キュイーン) | 「心」ランプ。**先告知**(レバーの瞬間)と**後告知**(3 本止めた一瞬あと → 次の回転で 7 を揃える)もある |
| CoreHaptics の作り込み | レバー / 停止 / リーチの 3 連打 / リーチ中の心臓の鼓動(ループ) / タメのビルドアップ / 爆発後の地鳴り / ファンファーレのリズム / キュイーンの鋭さが上がる振動 |

## スペック(テスト用)

| 項目 | 値 |
|---|---|
| BIG(16G・1G 8 枚) | 1/80 |
| REG(6G・1G 8 枚) | 1/110 |
| RUSH 中のボーナス | 1/14.5(15G で約 66% 継続) |
| 小役 | リプレイ 1/7.3、ベル 1/12(8 枚)、スイカ 1/50(10 枚)、チェリー 1/40(4 枚) |
| 機械割 | 約 101%(RUSH 込み、300 万回転のシミュレーション) |

メダルはただの数字で、お金とは交換できません。

## 構成

```
Kokoro/
  App/KokoroApp.swift          起動
  Slot/
    SlotSymbol.swift           図柄とリール配列
    SlotLottery.swift          内部抽選と演出の台本(SpinPlan)
    ReelMotion.swift           リールの動き(時刻 → 位置の純粋関数。減速・バウンド・粘り・通り過ぎ)
    SlotGame.swift             状態と演出の段取り(静寂 → タメ → 開放 など)
  Effects/
    SoundSynth.swift           効果音・BGM の波形合成
    SoundEngine.swift          AVAudioEngine で鳴らす
    HapticEngine.swift         CoreHaptics の振動パターン
    ParticleSystem.swift       紙吹雪・メダル・火花・吸い込まれる光
  Views/                       画面(背景・筐体・リール・ボタン・フラッシュ・大文字・PUSH)
```
