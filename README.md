# Kokoro

school_Message の issue #87(スロット案の素材)と #91(コード例)を元にした、
**スロットの演出を本気で作り込んだ試作アプリ**です。本番(school_Message)に入れる前に、
演出の気持ちよさ・テンポ・振動・長く遊べる仕組みをこのアプリで試します。自分用なので、保存などは簡易的です。

> issue では「パチンコ」と書いていますが、中身はスロット(パチスロ)です。

## 動かし方

1. `Kokoro.xcodeproj` を Xcode 16 以降で開く
2. **Signing & Capabilities** で自分の Team を選ぶ(Bundle ID は `app.takaoka.com.kokoro`)
3. **iPhone 実機**で実行する(振動は Taptic Engine のある iPhone だけ。iPad とシミュレータでは振動しません)

iOS 17 以上。外部ライブラリ・音声ファイル・画像素材は使っていません(効果音と BGM はその場で波形を合成しています)。

## 遊び方

1. **ホール**で台を選ぶ(101〜108 番台)。台の上のデータランプ(回転数・BIG/REG・履歴)を見て、設定が良さそうな台を探す
2. **START**(またはリールをタップ)でレバーオン。1 回 3 枚
3. **STOP** を左から順に押す(リールをタップしても次のリールが止まる)
4. 中段に **7 7 7 = BIG**、**BAR BAR BAR = REG**。BIG のあとは **KOKORO RUSH**
5. ボーナス・RUSH・チャンスゾーン中は席を立てません(左上の番号ボタンでホールへ戻る)

## 設定(1〜6)と台選び

- 各台の設定は **毎日 0:00(日本時間)に入れ替わる**。日付と台番号から決まるので、同じ日なら何度開いても同じ
- 配分は 設定1: 30% / 2: 20% / 3: 20% / 4: 15% / 5: 10% / 6: 5%
- 推測の材料: BIG・REG・ベルの確率(台データ画面に 1/x で出る)、**ボーナス終了時の示唆**(🔵 奇数寄り / 🔴 偶数寄り / 🟡 設定4以上 / 🌈 設定6)
- 台データ画面の「答え合わせ」で設定を見られる(見るとその日はホールにも表示)

| 設定 | BIG | REG | ベル | 機械割 |
|---|---|---|---|---|
| 1 | 1/138 | 1/180 | 1/13.2 | 97.4% |
| 2 | 1/133 | 1/172 | 1/13.0 | 98.7% |
| 3 | 1/128 | 1/163 | 1/12.8 | 100.3% |
| 4 | 1/122 | 1/152 | 1/12.5 | 103.1% |
| 5 | 1/116 | 1/142 | 1/12.2 | 105.1% |
| 6 | 1/109 | 1/132 | 1/11.9 | 108.0% |

機械割は RUSH・天井・ゾーン・フリーズ込みで、Python で 400 万回転シミュレーションした値です。

## ゲームの流れ

| 状態 | 中身 |
|---|---|
| BIG / REG | 16G / 6G、1G ごとに 8 枚(差し引き +5 枚) |
| KOKORO RUSH | BIG 後(と RUSH 中のボーナス後)に 15G。ボーナス合算 1/14.5 で **継続 約66%** |
| SUPER KOKORO RUSH | RUSH で **4 連目** に届くか、RUSH 中のスイカ(1/3)で昇格。**継続 約80%**。上パネルに「あと1連でSUPER!」 |
| チャンスゾーン | RUSH を 1 回も引き戻せずに終わった(駆け抜け)ら 30G、ボーナス確率 2 倍 |
| 天井 | 600G ハマったら次は虹リーチで BIG |
| ロングフリーズ | 1/4000。暗転 → 無音 → 鼓動 → 逆回転 → 7 がひとつずつ止まる → BIG + SUPER RUSH |

## 演出

- **静寂 → タメ → 爆発**: 最後の STOP で音・振動・BGM を全部切って暗転 → 期待度の色が段階的に上がるタメ → 爆発(白フラッシュ・紙吹雪・メダル・最大強度の振動・ファンファーレ)
- **寸止めは赤以上だけ**: 赤・金・虹のリーチは 7 が中段の半コマ上で粘り、ハズレると通り過ぎて「あと1コマ…」。青・緑はリールが回ったままサクッと答え(タメも 1.0〜1.2 秒)
- **裏ボタン(タメスキップ)**: 赤以上のタメ中にリールを叩くと、タメを飛ばして一発で告知
- **違和感**: 50 回に 1 回くらいの「いつもと違う」前兆。出たらボーナス期待度 約35%(ふだんの約 25 倍)
  - 「心」ランプが 0.05 秒だけ点いて消える
  - レバー音がいつもより少し高い
  - レバーの振動が「トトン」と一瞬ズレる
- **チャンスボタン**: 赤以上で PUSH! / 連打!!(12 回でゲージ満タン)
- **告知**: 「心」ランプのキュイーン。先告知(レバーの瞬間)・後告知(止めた一瞬あと → 次の回転で揃える)
- リーチ信頼度: 青 3% / 緑 9% / 赤 44% / 金 78% / 虹 100%

## 実績・図鑑・カスタマイズ

12 個の実績(1,000 回転 / 10,000 回転 / リーチ色コンプ / 1G 連 / フリーズ / 5 連 / 10 連 / SUPER 突入 / 天井 / 違和感から当選 / 一撃 1,000 枚 / 虹の示唆)。
解除すると **筐体の色**(ネオンブルー・サクラ・ゴールド・漆黒・レインボー)と **BGM**(ハイテンポ・8bit・マイナー)が増えます。
演出図鑑には見たリーチ色・違和感の回数・フリーズ回数・最大連チャン・RUSH 最高獲得を記録します。

## データの持ち方(将来の多人数を見据えて)

- **台のデータ**(その日の回転数・BIG/REG・ベル回数・履歴・示唆・答え合わせ)は `HallStore` が台番号ごとに持つ
- **プレイヤーのデータ**(メダル・実績・図鑑・見た目の設定)は `PlayerStore` が持つ
- 台には「座っている人」(`MachineData.occupant`)の欄があり、いまは自分だけなので `"me"` か空。
  将来は多人数で同じホールを共有し、ここにプレイヤー ID を入れて「その台は使用中」にできる形にしてある
  (ホールのカードは他の人が座っている台を「使用中」で押せないようにしてある)

どちらも端末の UserDefaults に保存するだけの簡易版です。

## 構成

```
Kokoro/
  App/KokoroApp.swift          起動、ホール ⇄ 台 の切り替え
  Hall/Hall.swift              台番号・日替わり設定・台データ(HallStore)
  Player/
    PlayerStore.swift          メダル・実績・図鑑・見た目の設定
    Achievements.swift         実績・筐体の色・BGM の種類
  Slot/
    SlotSymbol.swift           図柄とリール配列
    SlotLottery.swift          内部抽選と演出の台本(設定・RUSH・天井・ゾーン・フリーズ・違和感・示唆)
    ReelMotion.swift           リールの動き(減速・バウンド・粘り・通り過ぎ・逆回転)
    SlotGame.swift             1 台に座っている間の状態と演出の段取り
  Effects/
    SoundSynth.swift           効果音・BGM の波形合成
    SoundEngine.swift          AVAudioEngine で鳴らす
    HapticEngine.swift         CoreHaptics の振動パターン
    ParticleSystem.swift       紙吹雪・メダル・火花・吸い込まれる光
  Views/                       ホール・台・筐体・ボタン・演出レイヤー・台データ・実績の画面
```

メダルはただの数字で、お金とは交換できません。
